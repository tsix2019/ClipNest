# ClipNest 1.1 Feature Batch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the feature batch in `docs/superpowers/specs/2026-10-21-v1.1-features-design.md`.

**Architecture:** Data changes (pin-to-top column, snippet creation) live in ClipNest.Data/Core with unit
tests; platform pieces (Win+V hook, font enumeration, update check) in ClipNest.Platform; UI in
ClipNest.App (PanelWindow, SettingsWindow, EditWindow).

**Tech Stack:** .NET 10, WinUI 3 (Windows App SDK), SQLite (own P/Invoke wrapper), xUnit, NativeAOT.

## Global Constraints
- No new NuGet packages (AOT, small size). Win32/DirectWrite via existing P/Invoke style.
- All user-visible strings in both `Strings/en-US.json` and `Strings/zh-CN.json`.
- Build: `. tools/env.sh; dotnet build src/ClipNest.App/ClipNest.App.csproj -c Release -p:Platform=x64`.
- Tests: `. tools/env.sh; dotnet test tests/<Project>`.
- Never record real clipboard content in screenshots/tests; the dev instance uses `CLIPNEST_DATA`.
